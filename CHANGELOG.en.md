# Changelog

## 0.10.1 — 09/11/2026
- Fixed error 740 when opening TeamSpeak: if TeamSpeak requires administrator rights, Windows now asks for them.

## 0.10.0 — 09/11/2026
- New mod cleanup menu: remove a whole preset or only some mods, with a search by name.
- Cleanup now only offers mods from presets: your compositions and other Steam subscriptions are no longer affected.
- A mod used by another preset is flagged and kept, unless you choose to remove it.
- You must type CONFIRM to validate a removal, and a window confirms when it is done.
- TeamSpeak now also opens when it is installed in your user folder, without administrator rights.
- Main screen reorganized: DLCs become chips below the mod list, which now uses the full width.
- Options reorganized: advanced settings are collapsed, and the preset source address is no longer shown.

## 0.9.0 — 07/11/2026
- Removed the Arma 3 unit option from the launch options.
- New Options checkbox: open TeamSpeak and connect to the community server when the game starts.

## 0.8.2 — 07/11/2026
- Faster startup: presets, servers and Steam load at the same time, without waiting for the update check.

## 0.8.1 — 07/11/2026
- Faster preset switching: a preset unchanged on the site opens without being downloaded again.
- Lighter startup: only presets changed on the site are downloaded, all at once.

## 0.8.0 — 07/11/2026
- Local presets: import your own preset from the My presets section. It stays on your PC only, and nobody else can access it.

## 0.7.0 — 07/11/2026
- Arrow next to the version number to check for updates at any time.

## 0.6.0 — 07/11/2026
- Changelog: click the version number to read it.

## 0.5.0 — 07/11/2026
- Player count and map shown next to each server.
- Discord and Website buttons at the top of the window.
- TeamSpeak and radio plugin check, with a button to install the plugin.
- Download size shown before mods are downloaded.
- The launcher minimizes when the game starts.
- Cleanup of unused mods, off by default, in Options.

## 0.4.2 — 07/11/2026
- More reliable reading of the site: an unexpected link can no longer empty the preset list.
- Your settings are kept, and reported if they become unreadable.
- A password typed just before clicking Play is now taken into account.
- Fixes for several display and selection issues.

## 0.4.1 — 07/11/2026
- Confirmation required before enabling BattlEye.
- Mods that need an update are shown in blue, with their count in the summary.

## 0.4.0 — 07/11/2026
- Direct connection to the Main, OPEX and Training servers, with a password.
- Status dot showing whether each server is online.
- Checkbox to start the game with BattlEye.
- The Launch game button becomes Play.

## 0.3.1 — 07/11/2026
- Update test release, with no visible change.

## 0.3.0 — 07/11/2026
- English version, selectable in Options.
- Plainer wording.
- Update button next to the version number.

## 0.2.0 — 06/11/2026
- Presets stay available when the site is down.
- DLC are disabled by default, and your choices are kept.

## 0.1.1 — 06/11/2026
- Update test release, with no visible change.

## 0.1.0 — 06/11/2026
- First release: preset selection, mod downloads, startup options and automatic updates.
